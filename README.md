# 📊 Sales-Analysis-Excel-Dashboard
Interactive Sales Analysis Dashboard built using Microsoft Excel, PivotTables, PivotCharts, and Slicers to analyze sales performance, product performance, regional sales, salesperson performance, units sold, and profitability.

## 📌 Project Overview

Sales Analysis is an interactive Microsoft Excel dashboard developed to analyze sales performance and generate meaningful business insights.

The project contains raw sales data, PivotTable-based analysis, interactive slicers, charts, and a final dashboard.

## 🎯 Project Objectives

- Analyze overall sales performance
- Identify top-performing products
- Analyze regional sales performance
- Compare salesperson performance
- Analyze units sold by product
- Analyze profitability
- Create an interactive sales dashboard

## 🛠️ Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel Formulas
- Data Visualization

## 📂 Workbook Structure

### 1. SalesData

Contains 51 rows of sales records with information such as:

- Date
- Sales Person
- Region
- Product
- Units Sold
- Unit Price
- Cost of Goods
- Total Sales
- Profit

### 2. Pivot Table

Used for analysis and data summarization.

Includes:

- Total Sales by Region
- Total Sales by Product
- Units Sold by Product
- Total Sales by Sales Person
- Region slicer
- Product slicer
- Sales Person slicer
- Supporting charts

### 3. Dashboard

The final interactive dashboard includes:

- Total Sales
- Average Sales
- Total Units Sold
- Total Profit
- Units Sold by Product
- Total Sales by Region
- Total Sales by Product
- Total Sales by Sales Person
- Region filter
- Product filter
- Sales Person filter
